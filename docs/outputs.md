# mskcc/tempo: Output Guide

## Overview

This document describes the output directory structure and file formats generated by the TEMPO pipeline. All paths are relative to the base results directory specified with `--outdir`.

The pipeline organizes outputs into the following main directories:

```shell
results/
├── fastqc/
├── fastp/
├── alignment/
├── somatic/
├── facets/
├── msi/
├── hla/
├── germline/
├── qc/
├── multiqc/
└── pipeline_info/
```

## Sequence Quality Control

### FastQC Output

The `fastqc/` directory contains raw sequence quality reports:

```shell
results/fastqc/
├── sample1_normal_L001_R1_fastqc.html
├── sample1_normal_L001_R2_fastqc.html
├── sample1_normal_L002_R1_fastqc.html
├── sample1_tumor_L001_R1_fastqc.html
└── ...
```

- One report per FASTQ file (R1 and R2 for each lane)
- HTML format for interactive viewing
- Evaluates per-base quality, sequence composition, and quality scores

### Fastp Trimming Output

The `fastp/` directory contains read trimming reports and trimmed FASTQ files:

```shell
results/fastp/
├── sample1_normal_L001.fastp.html
├── sample1_normal_L001.fastp.json
├── sample1_normal_L001_R1.fastp.fastq.gz
├── sample1_normal_L001_R2.fastp.fastq.gz
└── ...
```

- `*.fastp.html` - Interactive quality control report
- `*.fastp.json` - Machine-readable statistics
- `*_R1.fastp.fastq.gz` - Trimmed forward reads
- `*_R2.fastp.fastq.gz` - Trimmed reverse reads

## Alignment and BAM Processing

The `alignment/` directory contains final aligned BAM files and quality metrics:

```shell
results/alignment/
├── sample1_normal.bam
├── sample1_normal.bam.bai
├── sample1_normal.bam.flagstat
├── sample1_normal_metrics.txt
├── sample1_normal_AlignmentSummaryMetrics.txt
├── sample1_tumor.bam
├── sample1_tumor.bam.bai
└── ...
```

### BAM File Outputs

- `*.bam` - Final, sorted, deduplicated, base-quality recalibrated BAM file
- `*.bam.bai` - BAM index file (binary index format)
- `*.bam.flagstat` - Samtools flagstat summary statistics
- `*_metrics.txt` - Picard MarkDuplicates metrics
- `*_AlignmentSummaryMetrics.txt` - Picard CollectAlignmentSummaryMetrics report

### Per-Sample Alignment Metrics

Each sample has quality metrics that include:
- Number of reads aligned
- Mapping quality distribution
- Duplication rates
- Insert size distribution
- Strand bias metrics

### Mutect2 Somatic SNVs

- `*.mutect2.vcf.gz` - Raw Mutect2 variant calls
- `*.mutect2.filtered.vcf.gz` - Filtered high-confidence Mutect2 calls
- Quality metrics and contamination estimates included in VCF header

### Strelka2 Somatic Variants

- `somatic.snvs.vcf.gz` - Single nucleotide variants
- `somatic.indels.vcf.gz` - Insertions and deletions
- Per-variant quality scores and genotype information

### Manta Structural Variants

- `diplomaBND.vcf.gz` - Breakpoint and translocation calls
- Includes single-sample variant calls before filtering
- Copy number alterations can be inferred from CNV calls

### Delly Structural Variants

- `*.delly.vcf.gz` - Delly structural variant calls
- Includes translocations, inversions, and complex rearrangements
- Per-variant support and quality metrics

### Combined Mutations

- `*.somatic.unfiltered.maf` - All mutations before filtering
- `*.somatic.final.maf` - Final filtered, annotated mutations
  - Includes variant effect predictions
  - Neoantigen predictions
  - Zygosity information
  - dbSNP and COSMIC annotations
- `intermediate_files/` - VCF files at different processing stages

### Copy Number Analysis (FACETS)

- `*.facets.seg` - Segmented copy number calls from FACETS (purity-adjusted)
- `*.purity.seg` - Copy number segments before purity correction
- `*.purity.ploidy.txt` - Sample purity and ploidy estimates
- `*.cna.txt` - Per-gene copy number status

### Concordance and Contamination

- `*.concordance.txt` - Tumor-normal pair concordance metrics
- `*.contamination.txt` - Estimated tumor sample contamination

## HLA Analysis

The `hla/` directory contains HLA typing and HLA-specific analyses:

```shell
results/hla/
├── polysolver/
│   ├── sample1_tumor.hla.txt
│   ├── sample1_tumor.winners.hla.txt
│   └── ...
├── lohhla/
│   ├── sample1_tumor__sample1_normal.hla_loss.txt
│   ├── sample1_tumor__sample1_normal.hla_predictions.txt
│   └── ...
└── neoantigen/
    ├── sample1_tumor.neoantigens.txt
    ├── sample1_tumor.netmhcpan.txt
    └── ...
```

### Polysolver HLA Typing

- `*.hla.txt` - All predicted HLA alleles with confidence scores
- `*.winners.hla.txt` - High-confidence HLA alleles (recommended for use)
- Format: HLA-A, HLA-B, HLA-C, HLA-DRB1, HLA-DQ, HLA-DP

### LOHHLA HLA Loss of Heterozygosity

- `*.hla_loss.txt` - Loss of heterozygosity calls per HLA allele
- `*.hla_predictions.txt` - HLA allele predictions with LOH status
- Indicates potential immune escape mechanisms

### Neoantigen Predictions

- `*.neoantigens.txt` - Predicted HLA-peptide binding
- `*.netmhcpan.txt` - NetMHCpan prediction output
- Includes mutation context, HLA allele, and binding affinity predictions

### MSIsensor-Pro Output

- `*.msi_score.txt` - Microsatellite instability score and classification
- `*.msi.json` - Per-microsatellite scoring data (machine-readable)

## File Formats Reference

### VCF Files

- `.vcf.gz` - Gzip-compressed Variant Call Format
- `.vcf.gz.tbi` - Tabix index for fast random access
- Standard format for variant data across the pipeline

### MAF Files

- Mutation Annotation Format (MAF) from TCGA
- Tab-delimited with standardized column definitions
- `*.final.maf` files are recommended for downstream analysis

### BAM Files

- Binary Alignment Format for sequencing reads
- `.bam.bai` index files enable random access
- All BAMs are sorted by genomic position

### SEG Files

- Segmented copy number format (tab-delimited)
- Columns: Sample, Chromosome, Start, End, Num_Probes, Segment_Mean
- Used by FACETS and other CNV analysis tools

### Coordinate Systems

All genomic coordinates follow standard conventions:
- 0-based half-open intervals in most internal tools
- 1-based closed intervals in BED and some report files
- GRCh37 (hg19) coordinates by default
