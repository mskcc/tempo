## Overview

TEMPO is a comprehensive Nextflow pipeline for cancer genomics analysis of whole exome sequencing (WES) and whole genome sequencing (WGS) data from tumor-normal sample pairs. It integrates multiple tools for:

- Alignment and quality control
- Somatic and germline variant calling
- Structural variant detection
- Copy number analysis
- HLA typing and neoantigen prediction
- Variant annotation and filtering
